log in this example is binary logarithm with is base 2, used to analyze algorithm efficiency

Binary Search algorithm:
O(log n)

simple algorith:
O(n)

binary search algorithm can only be used for already sorted data

some other common Big O run times from fastest to slowest:
O(log n) > O(n) > O(n log n) > O(n^2) > O(n!)

example:
O(log n) Binary Search
O(n) Simple Search
O(n log n) Quik Sort
O(n^2) Selection Sort
O(n!) Travelling Sales Person

n! is n factorial = n \* (n-1) \* (n-2) \* ... \* 2 \* 1
